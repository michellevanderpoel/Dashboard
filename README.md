# My Daily Dashboard

A personal daily-snapshot PWA: finance goals & subscriptions, fitness & healthy-eating adherence, cat vaccination/vet dates, trading/macro news debrief, and an AI email brief with one-tap approve drafts.

## Hosting (free)
- Hosted on GitHub Pages from this repo.
- Live URL: https://michellevanderpoel.github.io/dashboard/

## Install on iPhone / iPad
1. Open the URL in **Safari** (only Safari supports install on iOS).
2. Tap Share → **Add to Home Screen**.
3. It runs full-screen like a native app.

## Running costs
- Hosting: $0 (GitHub Pages)
- Data: $0 (compiled by her agent, encrypted with her passphrase)
- Everything else: $0

## How it works
The agent compiles her data (Obsidian vault ingests, news, email) into an encrypted snapshot and pushes it here. The app decrypts it on-device with her passphrase. Nothing sensitive is readable by anyone else.
